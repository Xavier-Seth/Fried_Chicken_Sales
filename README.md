# Fried Chicken Sales Calculator App

## Project Goal

Create a mobile application that calculates the total daily earnings of a fried chicken store.

The system calculates earnings based on:

- Delivered stock
- Remaining stock
- Item prices
- Starting cash in register

## Products

| Item          | Price |
| ------------- | ----- |
| Chicken Slice | ₱20   |
| Chicken Slice | ₱10   |
| Lumpia        | ₱5    |
| Rice          | ₱10   |

## Computation

Sold Items = Delivered - Remaining

Total Sales =  
(Chicken20 × 20) +  
(Chicken10 × 10) +  
(Lumpia × 5) +  
(Rice × 10)

Expected Cash =  
Starting Cash + Total Sales

## Example

Delivered:
Chicken ₱20 = 100  
Chicken ₱10 = 80  
Lumpia = 50  
Rice = 60

Remaining:
Chicken ₱20 = 20  
Chicken ₱10 = 10  
Lumpia = 5  
Rice = 15

Total Sales = ₱2,975
